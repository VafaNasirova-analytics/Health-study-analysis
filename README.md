
# Hälsostudie – statistisk dataanalys

Individuell projektuppgift inom Data Scientist-utbildningen
vid EC Utbildning.

## Syfte

Syftet med projektet är att analysera hälsodata från
800 deltagare med hjälp av statistiska metoder och Python.

## Del 1 – Grundläggande analys och statistik

- Datainläsning och kontroll av datakvalitet
- Beskrivande statistik
- Datavisualisering
- Simulering av sjukdomsförekomst
- Konfidensintervall med normalapproximation och bootstrap
- Hypotesprövning med Welchs t-test
- Poweranalys med Monte Carlo-simulering

## Verktyg och bibliotek

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook
- Git och GitHub

## Projektstruktur

- `data/` – Dataset
- `notebooks/` – Statistisk analys och resultat
- `requirements.txt` – Pythonbibliotek
- `README.md` – Projektbeskrivning
